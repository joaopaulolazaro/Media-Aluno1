# Cálculo de Média Escolar 🎓

Este repositório foi criado para armazenar a resolução de um exercício acadêmico desenvolvido em *Java*. O objetivo principal do programa é realizar o cálculo da média de notas de um aluno e exibir o resultado no console.

## 📝 Sobre o Projeto
O código foi construído seguindo as orientações do professor, onde o programa deve calcular a média e exibir uma mensagem final que inclui o nome do aluno juntamente com o resultado obtido.

## 📁 Estrutura 
* src/MediaAluno.java: Arquivo principal contendo todo o código-fonte e a lógica do cálculo da média.

## 🚀 Como executar
1. Baixe o arquivo ou faça o clone deste repositório.
2. Abra a pasta do projeto em uma IDE Java (como o *IntelliJ IDEA*, Eclipse ou VS Code).
3. Localize o arquivo MediaAluno.java dentro da pasta src.
4. Clique com o botão direito e selecione *Run 'MediaAluno.main()'* para ver o resultado no console.
